## 2026-04-30

### Understanding `need-to-learn.md`

**Q:** What does `src/modules/order/need-to-learn.md` include?

**A:** It's a **learning checklist** from a developer working on the order module. Here's what each item means:

| Item | Explanation |
|---|---|
| **asyncHandler** | HOF that wraps async controllers — catches errors and passes them to Express error middleware, eliminating manual try/catch |
| **why class in service?** | Classes offer constructor-based dependency injection, better TypeScript inference, and easier testing vs plain objects |
| **meta ?** | Zod v4's `.meta()` attaches metadata (descriptions, examples, IDs) to schemas, primarily for OpenAPI docs |
| **schemaRegistry** | A registry that collects all Zod schemas so the OpenAPI generator can auto-build API documentation |
| **schemaRegistry.register(...)** | Registers a schema under a name so OpenAPI can reference it via `$ref` instead of duplicating definitions |
| **`z.infer<typeof Schema>`** | Extracts the TypeScript type from a Zod schema — single source of truth, types update automatically when schema changes |
| **`.meta({ id: "..." })`** | Zod v4 native way to tag schemas with an identifier for OpenAPI generation (alternative/complement to `schemaRegistry.register`) |
| **Prisma Client** | Auto-generated, type-safe database query builder — provides methods like `findMany`, `create`, `update` |
| **BaseRepository** | Generic CRUD base class that all repositories extend — provides standard operations so you don't rewrite common patterns |

The comments with `<!-- -->` are the developer's personal notes about what they need to dig into further.

### Is `BaseRepository` generated by Prisma?

**Q:** Is `base.repository.ts` generated by Prisma?

**A:** **No.** It is **manually written** by the team. Here's the distinction:

| What | Source |
|---|---|
| `src/shared/repositories/base.repository.ts` | **Hand-written** — a generic CRUD wrapper that delegates to Prisma |
| `src/generated/prisma/` | **Auto-generated** by running `npm run db:generate` from your Prisma schema |

`BaseRepository` is a **thin typed wrapper** around Prisma's model delegates. It imports from the generated Prisma client (line 1), but every method (`findMany`, `create`, `update`, etc.) was written by a developer to provide a consistent interface across all modules.

Think of it this way:
- **Prisma generates** types and query methods based on `prisma/schema.prisma`
- **`BaseRepository`** wraps those generated methods so each module's repository gets free CRUD without rewriting boilerplate
